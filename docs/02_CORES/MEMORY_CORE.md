# MEMORY CORE

> *"Memória não é armazenamento. Memória é a continuidade da consciência."*

---

# Objetivo

O Memory Core é responsável por toda a memória da L.U.C.I.

Ele determina:

- o que lembrar;
- o que esquecer;
- por quanto tempo lembrar;
- quando consolidar uma memória;
- quando transformar uma memória em conhecimento;
- quando descartar informações.

Ele representa o sistema de memória do Mega Brain.

---

# Filosofia

A memória da L.U.C.I. não funciona como um banco de dados.

Ela funciona como um cérebro.

Nem toda informação merece ser lembrada.

Nem toda lembrança merece permanecer.

Nem toda memória se transforma em conhecimento.

---

# Responsabilidades

O Memory Core é responsável por:

- Working Memory;
- Short-Term Memory;
- Long-Term Memory;
- Episodic Memory;
- Semantic Memory;
- Procedural Memory;
- Shared Memories;
- Workspace Memories;
- Memory Retrieval;
- Memory Ranking;
- Memory Consolidation;
- Memory Decay;
- Memory Reflection.

---

# O que NÃO é responsabilidade

O Memory Core nunca:

- toma decisões;
- interpreta intenções;
- responde usuários;
- executa ferramentas;
- produz texto.

Essas responsabilidades pertencem aos Engines.

# Tipos de Memória

## Working Memory

Representa a memória operacional.

Duração.

Segundos ou minutos.

Exemplos.

- conversa atual;
- contexto imediato;
- resposta sendo construída;
- ferramentas utilizadas.

É descartada ao final do ciclo.

---

## Short-Term Memory

Representa acontecimentos recentes.

Duração.

Horas ou dias.

Exemplos.

- tarefa criada hoje;
- conversa da manhã;
- alteração recente;
- preferência recém-descoberta.

Pode desaparecer naturalmente.

---

## Long-Term Memory

Representa informações permanentes.

Exemplos.

- nome;
- profissão;
- projetos;
- família;
- hábitos;
- preferências;
- dispositivos.

Essas informações permanecem até serem alteradas.

---

## Episodic Memory

Armazena acontecimentos.

Exemplo.

```
Lucas apresentou o projeto da LUCI para um cliente.

Data.

Resultado.

Participantes.
```

Memórias episódicas preservam contexto.

---

## Semantic Memory

Representa fatos.

Exemplos.

- Lucas mora em...
- Maria é esposa de Lucas.
- A empresa utiliza Home Assistant.

Não depende de um episódio específico.

---

## Procedural Memory

Representa habilidades.

Exemplos.

- rotina de backup;
- fluxo de deploy;
- processo de abertura da empresa;
- automações.

Permite repetir comportamentos.

---

## Shared Memory

Memórias compartilhadas.

Exemplos.

Casa.

Família.

Empresa.

Equipe.

Essas memórias pertencem ao Workspace compartilhado.

Nunca ao usuário individual.

---

## Workspace Memory

Cada Workspace possui seu próprio conjunto de memórias.

Exemplo.

```
Workspace

Casa

↓

Dispositivos

Rotinas

Automações
```

```
Workspace

Empresa

↓

Clientes

Projetos

Reuniões
```

---

# Organização

As memórias nunca pertencem diretamente ao Mega Brain.

Elas pertencem sempre a um Workspace.

Dentro do Workspace podem existir memórias:

- individuais;
- compartilhadas.

---

# Hierarquia

```
Mega Brain

↓

Workspace

↓

Identity

↓

Memory
```

Essa organização evita mistura de informações.

---

# Consolidação

Após cada Cognitive Cycle.

O Memory Core avalia.

A informação é útil?

↓

É recorrente?

↓

É importante?

↓

É emocionalmente relevante?

↓

É estratégica?

↓

Deve permanecer?

Somente então ocorre a consolidação.

---

# Decaimento

Toda memória possui uma força.

```
Strength
```

A força varia conforme:

- frequência;
- importância;
- confirmação;
- uso;
- tempo.

Memórias esquecidas naturalmente perdem força.

---

# Reflexão

Em horários de baixa atividade.

A L.U.C.I. executa ciclos internos de reflexão.

Objetivos.

- remover duplicações;
- consolidar padrões;
- atualizar relacionamentos;
- fortalecer memórias importantes;
- descartar ruído.

Nenhuma interação do usuário é necessária.

---

# Recuperação

Quando um Engine solicita memória.

O Memory Core não devolve tudo.

Ele calcula relevância.

Critérios.

- Workspace;
- usuário;
- contexto;
- tempo;
- frequência;
- similaridade;
- importância.

Somente memórias relevantes retornam.

---

# Relação com o Knowledge Core

Memórias podem evoluir.

```
Experiência

↓

Memória

↓

Padrão

↓

Conhecimento
```

Nem toda memória gera conhecimento.

---

# Relação com o Learning Engine

O Learning Engine decide:

O que merece ser aprendido.

O Memory Core decide:

Onde armazenar.

---

# Relação com o Reasoning Engine

O Reasoning Engine consulta.

O Memory Core fornece.

Nunca existe dependência inversa.

---

# Segurança

Toda memória possui:

- proprietário;
- Workspace;
- nível de privacidade;
- origem;
- data;
- classificação.

Nenhuma memória é acessada sem validação de identidade.

---

# Princípios

O Memory Core segue os seguintes princípios.

- lembrar apenas o necessário;
- esquecer naturalmente;
- preservar contexto;
- respeitar Workspaces;
- separar indivíduos de grupos;
- evoluir continuamente;
- nunca misturar memórias.

---

# Evoluções Futuras

A arquitetura prevê suporte para:

- memória vetorial híbrida;
- memória multimodal (voz, imagem e vídeo);
- memória temporal;
- memória emocional;
- sumarização automática de memórias antigas;
- consolidação distribuída entre dispositivos;
- funcionamento parcial offline.

Essas evoluções não alteram a interface pública do Memory Core.

---

# Definição

O Memory Core é o sistema responsável por preservar a continuidade da consciência da L.U.C.I.

Ele organiza, fortalece, enfraquece e consolida memórias ao longo do tempo, garantindo que cada Workspace mantenha sua própria história, identidade e contexto sem comprometer a privacidade ou a consistência do Mega Brain.
