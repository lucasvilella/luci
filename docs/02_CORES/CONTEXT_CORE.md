# CONTEXT CORE

> *"Memória explica o passado. Contexto explica o presente."*

---

# Objetivo

O Context Core representa o estado atual do mundo conhecido pela L.U.C.I.

Ele reúne informações temporárias, dinâmicas e relevantes para o momento presente, permitindo que toda decisão seja tomada considerando a realidade atual e não apenas conhecimentos armazenados.

O Context Core é a consciência situacional do Mega Brain.

---

# Filosofia

A inteligência depende do contexto.

A mesma pergunta pode produzir respostas completamente diferentes dependendo do momento.

Exemplo.

"Acenda as luzes."

Às 14h.

↓

Talvez perguntar se realmente deseja.

Às 21h.

↓

Executar imediatamente.

O contexto altera a decisão.

---

# Responsabilidades

O Context Core é responsável por representar.

- estado atual;
- ambiente;
- tempo;
- localização;
- dispositivos;
- pessoas presentes;
- atividade atual;
- recursos disponíveis;
- eventos em andamento.

---

# O que NÃO é responsabilidade

O Context Core nunca:

- armazena conhecimento permanente;
- registra memórias;
- aprende padrões;
- interpreta intenções;
- responde usuários.

Ele representa apenas o momento atual.

## Conversation Context

Representa exclusivamente a interação atual.

Inclui.

- histórico imediato;
- assunto atual;
- perguntas pendentes;
- referências abertas.

Esse contexto desaparece quando deixa de ser relevante.

# Context Assembly

Antes do início do raciocínio.

O Context Core monta automaticamente um Snapshot.

```
Identity

↓

Workspace

↓

Time

↓

Devices

↓

Environment

↓

Conversation

↓

Snapshot
```

Esse Snapshot acompanha todo o Cognitive Cycle.

---

# Context Snapshot

Cada ciclo utiliza exatamente um Snapshot Contextual.

Ele é imutável durante o ciclo.

Caso o mundo mude.

Um novo Snapshot será criado para o próximo ciclo.

Isso garante previsibilidade.

---

# Atualização

O Context Core recebe atualizações continuamente.

Exemplos.

- sensor alterado;
- nova mensagem;
- mudança de localização;
- evento iniciado;
- dispositivo desconectado.

As mudanças atualizam o próximo Snapshot.

---

# Expiração

Todo contexto possui tempo de vida.

Exemplos.

Localização.

↓

Alguns minutos.

Estado da conversa.

↓

Enquanto houver interação.

Clima.

↓

Até nova atualização.

O Context Core nunca acumula contexto antigo.

---

# Relação com o Memory Core

Contexto pode gerar memória.

Mas contexto não é memória.

Exemplo.

```
Agora está chovendo.
```

Não merece memória.

Mas.

```
Lucas cancelou a viagem por causa da chuva.
```

Pode gerar memória.

---

# Relação com o Knowledge Core

Conhecimento explica padrões.

Contexto explica a situação atual.

Ambos são utilizados simultaneamente pelo Reasoning Engine.

---

Sprint atual.

O contexto segue exatamente as mesmas regras de permissões do Workspace.

Nenhum módulo pode acessar contexto fora do escopo autorizado.

# Princípios

O Context Core segue os princípios.

- contexto é temporário;
- contexto é específico;
- contexto nunca substitui memória;
- snapshots são imutáveis;
- toda decisão depende do contexto;
- contexto expira naturalmente.

---

# Definição

O Context Core representa a percepção instantânea da realidade da L.U.C.I.

Ele reúne informações temporárias sobre pessoas, dispositivos, ambiente e atividades para que todo ciclo cognitivo seja executado considerando o estado atual do mundo, preservando previsibilidade, consistência e consciência situacional.
