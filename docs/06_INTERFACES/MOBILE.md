# MOBILE INTERFACE

> *"O celular é a presença contínua da L.U.C.I. ao lado do usuário."*

---

# Objetivo

A Interface Mobile representa a principal forma de interação cotidiana com a L.U.C.I.

Ela foi projetada para acompanhar o usuário durante todo o dia, oferecendo uma experiência rápida, contextual e altamente integrada aos recursos do dispositivo.

Seu foco não é reproduzir o Desktop.

Seu foco é oferecer inteligência no momento certo.

---

# Filosofia

O Mobile acompanha o usuário.

Enquanto o Desktop é um ambiente de trabalho, o celular representa a presença permanente da L.U.C.I.

Cada interação deve considerar o contexto atual do usuário.

---

# Princípio Fundamental

O Mobile privilegia contexto e velocidade.

Toda informação apresentada deve ser relevante para o momento.

---

# Responsabilidades

A Interface Mobile é responsável por:

- conversação por texto e voz;
- captura de imagens;
- captura de documentos;
- compartilhamento rápido;
- notificações inteligentes;
- interação com localização;
- integração com sensores do dispositivo.

---

# O que NÃO é responsabilidade

O Mobile nunca:

- executa raciocínio;
- mantém memória própria;
- toma decisões cognitivas;
- executa ferramentas diretamente.

Toda inteligência permanece centralizada.

---

# Companion Mode

O Mobile funciona como um acompanhante digital.

Ele observa o contexto do dispositivo para enriquecer a experiência.

Exemplos.

- localização;
- movimento;
- bateria;
- conectividade;
- dispositivos próximos;
- horário;
- modo do aparelho.

Essas informações enriquecem o Context Core.

# Princípios

A Interface Mobile segue os princípios.

- contexto antes de quantidade;
- velocidade antes de profundidade;
- presença contínua;
- continuidade entre dispositivos;
- adaptação ao ambiente;
- inteligência centralizada.

---

# Definição

A Interface Mobile representa a presença permanente da L.U.C.I. junto ao usuário, oferecendo uma experiência contextual, multimodal e altamente integrada aos recursos do dispositivo. Seu objetivo é disponibilizar a inteligência da plataforma no momento certo, em qualquer lugar, preservando a continuidade da Session e o acesso ao mesmo estado cognitivo existente nas demais Interfaces.
